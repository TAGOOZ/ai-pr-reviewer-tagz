# Development Guidelines

- Prefer `uv` over `pip`
- Write real tests without mocking—ensure tests validate actual behavior
- Execute commands via `uv run`, not `python` directly
- YouTube transcripts: use `youtube-transcript-api VIDEO_ID` with `uv run`
- No emojis in pull requests
- Avoid fabricated case studies and metrics
- Never use `git add .`—stage files individually
- Include tests when planning work
- Work on branches, not main (unless authorized)
- Commit frequently in logical groups with targeted file staging
- "Sacrifice grammar for the sake of concision"
- List any unresolved questions at the end, if any
