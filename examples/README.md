# Real Integration Test Example

This directory contains examples of real code changes to test the CodeRabbit AI review system.

## Purpose

These files are intentionally designed with various issues that CodeRabbit should detect:
- Security vulnerabilities
- Code quality issues
- Performance issues
- Style issues

## Examples

### 1. Security Issues

See `security_vulnerability_example.py` for examples of:
- SQL injection vulnerabilities
- Command injection risks
- Unsanitized user input

### 2. Code Quality Issues

See `code_quality_example.py` for examples of:
- Unnecessary complexity
- Dead code
- Poor error handling

### 3. Performance Issues

See `performance_example.py` for examples of:
- N+1 query patterns
- Inefficient loops
- Memory leaks

## Running CodeRabbit Review

To trigger CodeRabbit AI review on these examples:

1. Create a PR with changes to these files
2. Configure CodeRabbit to review the repository
3. Check the generated review comments

Expected CodeRabbit feedback:
- Security warnings for vulnerable patterns
- Code quality suggestions
- Performance optimization tips
- Style recommendations
